git init: este comando sirve para que una carpeta normal en la computadora se convierta enn un repositorio de git.
git clone: este descarga y copia un repositorio de git directamente a la computadora.
git status: este sirve para mostrar en que estado actual del repositorio. o sea, que cosas cambiaron y que cosas estan preparadas.
git add: este prepara los cambios necesarios y los archivos modificados para que esten listos para el registro.
git commit: este guarda una version de los cambios con un mensaje.
git push: este sube los cambios hechos en la coputadora directamente a github.
git pull: este trae los cambios nuevos de github a la computadora.
git branch: este crea una rama o muestra las que existen.
git switch:este cambia a otra rama de trabajo.
git merge: une una rama con la que estamos usando.
git log: muestra el historial de commits.
